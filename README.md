# 🍔 FastFood Website

Современный, адаптивный и визуально привлекательный веб-сайт для ресторана быстрого питания. Проект включает в себя меню, блок с акциями, отзывы клиентов и интерактивную форму заказа.

---

## 🚀 Особенности (Features)

* **Полная адаптивность:** Сайт отлично отображается на смартфонах, планшетах и компьютерах.
* **Интерактивное меню:** Разделение по категориям (Бургеры, Пицца, Закуски, Напитки) с анимацией при наведении.
* **Блок спецпредложений:** Яркие баннеры для отображения текущих акций и скидок.
* **Плавная навигация:** Удобное меню со скроллом к нужным секциям страницы.
* **Форма обратной связи:** Стилизованная форма для бронирования столов или предзаказа.

---

## 🛠️ Стек технологий (Tech Stack)

* **HTML5:** Семантическая структура веб-страницы.
* **CSS3:** Кастомные стили, сетки (Flexbox/Grid) и плавная анимация.
* **JavaScript:** Логика открытия мобильного меню и валидация формы.
